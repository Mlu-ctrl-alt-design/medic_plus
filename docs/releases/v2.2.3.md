# v2.2.3 — 2026-05-10

UI polish in the Daystar Health SPA's new-visit drawer.

## What's new

**Branded `MTextArea` component.** The five SOAP textareas in the new-visit drawer (HOPI, Subjective, Objective, Assessment, Plan) used bare `<textarea className="input">` wrappers. Inconsistent with the rest of the daystar-health portal, which already uses branded `window.M*` components for date, time, and select inputs.

`MTextArea` matches the existing branded-input API:

- `label`, `hint`, `isRequired`, `placeholder`, `rows`, `value`, `onChange` (string, not event)
- Vertical-only manual resize (no auto-resize)
- Hint wired via `aria-describedby`; `isRequired` adds `aria-required` and a visible asterisk
- `aria-invalid` passthrough for future validation wiring
- Visual style matches `MDatePicker` / `MTimePicker` (border, focus ring, label typography)
- CSS lives under the `.mta-*` prefix in `meridian.css`, mirroring `.mdp-*` and `.mtp-*`

All five new-visit drawer textareas now use `MTextArea`. The `NVField` label wrapper is dropped — the component owns its own label.

## Upgrade impact

UI-only. No schema changes, no fixture changes, no migration impact. Frontend assets rebuild via `bench build --app medic_plus`.
